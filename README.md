# Arduino LED Blinking Project

## Objective
To control an LED using an Arduino and make it blink at a fixed interval.

## Components
- Arduino Uno
- LED
- 220Ω resistor
- Breadboard
- Jumper wires

## Working
The Arduino sets the LED pin as an output. The LED is switched ON for
one second and OFF for one second continuously.

## Expected Output
The LED should blink continuously with a 1-second ON and 1-second OFF interval.

## QA Approach
The project is tested for:
- LED connection
- Correct GPIO pin
- Blinking timing
- Program compilation
- Power supply
